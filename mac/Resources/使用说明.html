ToastFish

在 macOS 通知里背单词。点菜单栏上的小鱼图标打开菜单。

第一次使用

  1. 点 开始！，在弹出的对话框里允许 ToastFish 发送通知。
  2. 打开 系统设置 → 通知 → ToastFish，把通知样式设为 提醒。横幅样式几秒后就会消失，按钮也会跟着消失。
  3. macOS 会把多个按钮收在通知的 选项 里：鼠标移到通知上，点“选项”即可选择。

基本流程

  1. 英语词汇 或 日语词汇 里选一本词库，通知会显示当前进度。
  2. 参数设置 → 单词个数 设定这次背多少个。
  3. 点 开始！（或按 ⌥Q）。英语词库按记忆曲线安排新词和复习词，每个词选“没有印象 / 记忆模糊 / 暂时记住 / 已经牢记”。
  4. 背完后会测验记忆模糊的词：中译英和选择题，答错的会再考一次。

快捷键

⌥Q开始背单词
⌥1 – ⌥4点通知上的第 1 到第 4 个按钮
⌥`发音

⌥1–⌥4 和 ⌥` 只在背诵或测验进行时生效，其余时间这些按键照常输入字符。⌥Q 在 ToastFish 运行期间一直有效。

发音

英语发音来自有道词典，下载后缓存在本机；没有网络时使用系统语音。参数设置 → 英标类型 可在美音和英音之间切换，自动播放 控制每个词出现时是否自动朗读。日语发音需要系统里有日语声音：系统设置 → 辅助功能 → 朗读内容 → 系统声音 → 管理声音。

背诵记录与导入

开启 自动日志 后，每次用内置词库背诵或测验，都会生成一个 Excel 文件，位置见 参数设置 → 打开背诵记录文件夹。导入单词 可以选择英语和日语的背诵记录重新背诵（五十音记录不能导入），也可以导入按自定义模板填写的 Excel（参数设置 → 显示自定义模板）。仅支持 .xlsx 格式。

其他

  • 重置进度：把当前词库恢复为未学习。
  • 开机启动：登录时自动打开 ToastFish。
  • 学习进度保存在 ~/Library/Application Support/ToastFish/，更新应用不会覆盖。
